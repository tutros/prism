  <files>backend/app/services/criteria_service.py</files>
  <action>
  Create new service file with two async functions:

  1. async def go_deeper(comparison: ComparisonResult, research_a: dict, research_b: dict) -> list[Criterion]:
     """Generate 2-3 additional criteria using cached research."""

     Build prompt that:
     - Lists existing criteria names and descriptions to EXCLUDE
     - Asks for 2-3 NEW non-obvious criteria not already covered
     - Focuses on second-order effects, different perspectives, long-term tradeoffs
     - Uses same structured output pattern as claude_service

     Use Claude API with structured output (same model as claude_service).
     Return list of new Criterion objects with origin="ai".

  2. async def regenerate_weights(criteria: list[Criterion], intent: str) -> dict[str, float]:
     """Ask AI to re-weight all criteria based on intent."""

     Build prompt that:
     - Lists all criteria (AI and user) with name and description
     - Asks Claude to assign weights 0-100 based on intent
     - Weights should sum to approximately 100

     Return dict mapping criterion_id -> new_weight.

  Implementation notes:
  - Import get_anthropic_client from config
  - Use cache_control on system prompt (same pattern as claude_service)
  - Model: claude-sonnet-4-5-20250929
  - Handle JSON parsing with same fallback as claude_service

  Also update storage to cache research:
