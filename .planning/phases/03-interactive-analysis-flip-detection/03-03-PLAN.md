<task type="auto">
  <name>Task 1: Create flip detection service</name>
  <files>backend/app/services/flip_service.py</files>
  <action>
  Create flip_service.py with three functions:

  1. calculate_sensitivity(criteria: list[Criterion], weights: dict[str, float]) -> dict[str, float]:
     """Calculate sensitivity score (0-1) for each criterion."""
     - Sensitivity = |score_a - score_b| * normalized_weight
     - Normalize to 0-1 range (divide by max)
     - Higher = this criterion has more influence on outcome

  2. calculate_flip_analysis(criteria, weights, winner) -> list[FlipSuggestion]:
     """Calculate what weight changes would flip the winner."""
     - For each criterion where loser_score > winner_score:
       - Calculate required weight increase to flip outcome
       - Only include if change <= 50% (realistic threshold)
     - Sort by smallest change needed (most feasible first)
     - Return top 3 suggestions

     FlipSuggestion model (add to models.py or define in service):
     - criterion_id: str
     - criterion_name: str
     - current_weight: float
     - required_weight_increase: float
     - sensitivity_score: float

  3. async generate_actionable_suggestions(comparison, flip_analysis, research_a, research_b) -> list[ActionableSuggestion]:
     """Transform math into user-friendly actionable suggestions."""
     - Use Claude to convert "increase weight by X%" into realistic actions
     - Prompt MUST require source citations from research
     - Prompt MUST ban impossible suggestions (see research doc for banned patterns)
     - Return 2-3 actionable suggestions with source URLs

     ActionableSuggestion model:
     - action: str (e.g., "If you have access to local recycling...")
     - affected_criterion: str
     - impact: str
     - sources: list[str]

  Use same Claude API patterns as criteria_service.
  </action>
  <verify>

  </verify>
  <done>flip_service.py has sensitivity calculation, flip analysis, and actionable suggestion generation</done>
