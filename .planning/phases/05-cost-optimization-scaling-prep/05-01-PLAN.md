  <name>Task 1: Create usage_tracker.py and spending_guard.py</name>
  <files>backend/app/services/usage_tracker.py, backend/app/services/spending_guard.py</files>
  <action>
Create `backend/app/services/usage_tracker.py` with:

1. A `UsageRecord` dataclass with fields: `feature` (str: "criteria", "go_deeper", "regenerate_weights", "flip_suggestions"), `model` (str), `input_tokens` (int), `output_tokens` (int), `cache_creation_tokens` (int), `cache_read_tokens` (int), `cost_usd` (float), `timestamp` (str ISO format).

2. A `PRICE_PER_TOKEN` dict for model "claude-sonnet-4-5-20250929":
   - input: 3.00 / 1_000_000
   - cache_write: 3.75 / 1_000_000
   - cache_read: 0.30 / 1_000_000
   - output: 15.00 / 1_000_000

3. `calculate_cost(model: str, usage) -> float` that computes:
   `(usage.input_tokens * input_price) + ((usage.cache_creation_input_tokens or 0) * cache_write_price) + ((usage.cache_read_input_tokens or 0) * cache_read_price) + (usage.output_tokens * output_price)`

4. Module-level `_usage_records: list[dict] = []` and `_lock = threading.Lock()`.

5. `record_usage(feature: str, model: str, usage) -> UsageRecord` that:
   - Creates a UsageRecord from the response.usage object
   - Appends it (as dict) to `_usage_records` under lock
   - Persists the full list to `data/usage_metrics.json` using atomic write (same pattern as storage.py: tempfile + fsync + os.replace)
   - Calls `spending_guard.add_cost(record.cost_usd)` to auto-accumulate daily spend (import: `from .spending_guard import add_cost`)
   - Returns the UsageRecord

6. `get_usage_stats() -> dict` that returns aggregated stats:
   - total_input_tokens, total_output_tokens, total_cache_read_tokens, total_cache_creation_tokens
   - total_cost_usd
   - by_feature: dict mapping feature name to {count, cost_usd}
   - Load from `data/usage_metrics.json` on first call (lazy init).

7. On module load, try to read `data/usage_metrics.json` to restore `_usage_records` (so metrics survive server restarts).

Create `backend/app/services/spending_guard.py` with:

1. `_DAILY_CAP_USD = float(os.environ.get("DAILY_SPEND_CAP_USD", "5.0"))`
2. Module-level `_today: str`, `_daily_cost_usd: float = 0.0`, `_lock = threading.Lock()`
3. `check_spending_cap() -> None` that raises `ValueError` with message if daily spend >= cap. Day boundary check: if `date.today().isoformat() != _today`, reset counter.
4. `add_cost(cost: float) -> None` that increments `_daily_cost_usd` under lock (with same day boundary reset).
5. `get_daily_spend() -> dict` returning `{"cost_usd": _daily_cost_usd, "cap_usd": _DAILY_CAP_USD, "date": _today}`.

Important: Use `threading.Lock` (not asyncio.Lock) for both modules — these are fast in-memory operations called from sync context. The `data/` directory already exists and is gitignored.
  </action>
