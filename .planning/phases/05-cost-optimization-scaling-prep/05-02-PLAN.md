3. Modify `backend/app/services/tavily_service.py`:

Add imports at top:
```python
import asyncio
from datetime import datetime, timezone
from cachetools import TTLCache
```

Add module-level cache after the dataclass definitions:
```python
# In-memory cache for Tavily results: 200 entries max, 24h TTL
_TAVILY_CACHE: TTLCache = TTLCache(maxsize=200, ttl=86400)
_CACHE_LOCK = asyncio.Lock()
```

Add a `cached_at` field to `OptionResearch`:
```python
@dataclass
class OptionResearch:
    option: str
    results: list[SearchResult]
    error: str | None = None
    cached_at: str | None = None  # ISO timestamp if from cache
```

Modify `search_option()` to check cache before calling Tavily:
- Build cache key: `query.lower().strip()` (same query string already constructed)
- Check `_TAVILY_CACHE` under `_CACHE_LOCK`
- On hit: return `OptionResearch` with `cached_at` from stored entry
- On miss: call Tavily normally, store result and timestamp in cache, return with `cached_at=None`

Add a `force_refresh` parameter to `search_option(option: str, force_refresh: bool = False)`:
- If `force_refresh=True`, skip cache check and always call Tavily (but still store result in cache afterward)

Pass `force_refresh` through `search_both_options()` as well:
```python
async def search_both_options(option_a: str, option_b: str, force_refresh: bool = False) -> tuple[OptionResearch, OptionResearch]:
```

Important: The cache key should be the full query string (including the "hidden costs environmental impact..." suffix), NOT just the option name. This prevents collisions.
