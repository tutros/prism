3. Add the flag endpoint (after existing endpoints, before flip-analysis):
```python
@router.patch("/comparisons/{comparison_id}/sources/flag")
async def flag_source(comparison_id: str, body: SourceFlagRequest):
    """Toggle flagged state of a source URL.

    URL is passed in request body to avoid encoding issues with special characters.
    """
    result = storage.read_result(comparison_id)
    if not result:
        raise HTTPException(status_code=404, detail="Comparison not found")

    url = body.url
    flagged = body.flagged

    # Initialize source_metadata if empty (for old comparisons)
    if not hasattr(result, 'source_metadata') or result.source_metadata is None:
        result.source_metadata = {}

    # Get or create metadata entry for this URL
    if url in result.source_metadata:
        result.source_metadata[url].flagged = flagged
    else:
        # Create new entry with unknown quality (old comparison without metadata)
        result.source_metadata[url] = SourceMetadata(
            quality="unknown",
            flagged=flagged,
            last_verified=None,
        )

    storage.write_result(comparison_id, result)
    return {"url": url, "flagged": flagged}
```

IMPORTANT: Use request body for URL (not path/query param) to avoid URL encoding issues with source URLs containing ?, &, #, etc.
