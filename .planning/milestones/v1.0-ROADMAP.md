# Milestone v1.0: MVP

**Status:** SHIPPED 2026-02-14
**Phases:** 1-6
**Total Plans:** 20

## Overview

This roadmap delivered an AI-powered decision comparison tool that surfaces hidden costs and systemic impacts invisible in traditional comparisons. The six phases progressed from trust infrastructure (sources, human oversight) through AI integration (criteria discovery, weighting) to differentiation (flip analysis, confidence signals), scaling preparation (cost optimization), and tech debt cleanup. Every phase delivered verifiable user capabilities building toward the core value: surfacing invisible threads connecting choices to systemic impacts.

## Phases

### Phase 1: Foundation + Core Trust

**Goal:** Users can compare two options with source-cited information and see a clear winner based on adjustable weights.
**Depends on:** None (foundation)
**Plans:** 5 plans

Plans:
- [x] 01-01: Backend setup (FastAPI, Pydantic models, atomic JSON storage)
- [x] 01-02: Frontend setup (Vite + React + TanStack Query + Tailwind)
- [x] 01-03: Comparison flow (form, API integration, polling, display)
- [x] 01-04: Weight system (sliders, client-side recalculation)
- [x] 01-05: Persistence + polish (history, examples, responsive verification)

**Details:**
Established trust infrastructure before AI features. Used mock AI results initially to verify full stack communication. File-based JSON storage with atomic writes (tempfile + fsync + os.replace). Addressed critical pitfalls: source reliability, human oversight, mobile UX, cost monitoring setup. 12 requirements satisfied.

## Milestone Summary

**Key Decisions:**
- React + Vite over Next.js (simpler setup for POC, separate frontend/backend)
- Python + FastAPI for backend (great for AI integration, async-native)
- Claude + Tavily for AI + search (Claude for reasoning, Tavily for sourced research)
- File-based persistence for POC (avoid database complexity, migrate later)
- 3-5 criteria default with "Go Deeper" option (avoid information overload)
- Sliders + auto-recalc for weights (immediate feedback, intuitive UX)
- 202 Accepted + polling for async processing
- Atomic writes (tempfile + fsync + os.replace) for crash safety
- Client-side scoring for instant weight recalculation
- SSE for real-time progress streaming
- Tailwind v4 with @tailwindcss/vite plugin

**Issues Resolved:**
- Storage ValidationError on non-ComparisonResult JSON files in data/ directory
- Dedup logic intercepting before Tavily cache could set tavily_cached_at
- React state navigation vs window.location.reload()
- TanStack Query cache invalidation on dedup returning same comparison_id
- Spending guard not loading accumulated daily costs from disk on restart
- SSE EventSource using relative URL (failing silently against Vite dev server)
- Spending cap 429 error not surfacing detail message to users
- Missing Phase 3 VERIFICATION.md

**Issues Deferred:**
- DELETE criteria route has no frontend UI (not required by RES-06, optional v2 enhancement)

**Technical Debt Incurred:**
- Prompt caching annotation correct but inactive (system prompt ~150 tokens, below Anthropic minimum ~1024)
