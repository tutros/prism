# Requirements: Hidden Cost Comparator

**Defined:** 2026-02-01
**Core Value:** Surface the invisible threads that connect everyday choices to systemic impacts

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Input

- [x] **INP-01**: User can enter two options to compare (text fields)
- [x] **INP-02**: User can describe their intent/priorities in a text box
- [x] **INP-03**: User can click Compare to trigger AI analysis
- [x] **INP-04**: User sees example prompts to help get started

### Research

- [x] **RES-01**: AI researches both options via Tavily web search
- [x] **RES-02**: AI generates 3-5 non-obvious criteria (hidden costs, not obvious factors)
- [x] **RES-03**: Every criterion includes source citations (clickable links)
- [x] **RES-04**: User can "Go Deeper" to generate additional criteria
- [x] **RES-05**: Sources display quality indicators (peer-reviewed, government, blog, etc.)
- [x] **RES-06**: User can add/edit custom criteria alongside AI-generated ones

### Weights

- [x] **WGT-01**: AI generates initial weights based on user intent
- [x] **WGT-02**: System displays weighted scores for each option
- [x] **WGT-03**: User can adjust weights via sliders
- [x] **WGT-04**: Scores auto-recalculate when weights change
- [x] **WGT-05**: User can regenerate weights (re-prompts AI with intent)

### Results

- [x] **RST-01**: System shows clear winner with reasoning summary
- [x] **RST-02**: System shows "what would flip the outcome" for losing option
- [x] **RST-03**: Flip suggestions are realistic and actionable only
- [x] **RST-04**: Flip suggestions include source citations

### UX

- [x] **UX-01**: Loading states shown during AI processing
- [x] **UX-02**: Mobile responsive design
- [x] **UX-03**: Streaming responses show AI progress in real-time
- [x] **UX-04**: Results saved to JSON file (POC persistence)
- [x] **UX-05**: User can recall previous results by filename

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Sharing

- **SHR-01**: Shareable links to specific comparison results
- **SHR-02**: Database storage for persistent results
- **SHR-03**: Embed comparison results on other sites

### Advanced

- **ADV-01**: Compare more than 2 options
- **ADV-02**: User accounts to save comparisons
- **ADV-03**: Comparison history dashboard

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| User authentication | Anyone can use, no accounts for POC |
| Database storage | File-based for POC, migrate later |
| More than 2 options | Complexity explosion, keep v1 simple |
| Real-time price tracking | Maintenance burden, out of core value |
| Collaborative editing | Scope creep for MVP |
| Mobile native app | Web-first, responsive design sufficient |
